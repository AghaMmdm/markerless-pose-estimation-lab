# Notebooks Directory

Jupyter notebooks for interactive exploration, visualization, and documentation of experiments.

## Naming Convention

```
stage_<number>_<topic>.ipynb
exp_<id>_<method>.ipynb
```

Examples:
- `stage_1_video_processing.ipynb`
- `stage_2_movenet_inference.ipynb`
- `exp_001_movenet_baseline.ipynb`

## Guidelines

- One notebook per experimental stage or major analysis
- Keep notebooks focused and readable
- Export key figures to `reports/figures/`
- Document findings in `reports/experiment_log.md`
